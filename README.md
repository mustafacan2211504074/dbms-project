# FlavorFleet Development Branch

This branch serves as the **primary development environment** for the FlavorFleet database project.

All feature branches created by team members are merged into this branch before being finalized.

---

## Purpose of This Branch

The `dev` branch is used to:

- Integrate database features developed by each team member
- Test relational integrity
- Validate SQL scripts
- Review schema compatibility

Once all features are stable, the code will be merged into the **main branch**.

---

## Development Workflow

Each team member works in their own branch:

- member1-user-system
- member2-restaurant
- member3-product
- member4-order
- member5-review

Completed work is merged into the **dev branch** for integration.

---

## Development Goals

- Maintain a normalized database schema (3NF)
- Ensure relational integrity
- Implement SQL triggers and procedures
- Validate queries and joins

---

This branch represents the **active development stage of the project**.
